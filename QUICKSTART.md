# Quick Start Guide

## Installation (3 steps)

1. **Upload the plugin folder**
   - Copy the `capify-loan-calculator` folder to `/wp-content/plugins/`

2. **Activate the plugin**
   - Go to WordPress Admin → Plugins
   - Find "Capify Business Loan Calculator"
   - Click "Activate"

3. **Add to your page**
   - Edit any page or post
   - Add the shortcode: `[capify_loan_calculator]`
   - Publish!

## That's it! 🎉

Your business loan calculator is now live and ready to use.

## Common Customizations

### Change Currency to USD
```
[capify_loan_calculator currency_symbol="$"]
```

### Set Different Default Amount
```
[capify_loan_calculator default_amount="250000"]
```

### Change Interest Rate
```
[capify_loan_calculator default_rate="5.5"]
```

### Combine Multiple Options
```
[capify_loan_calculator default_amount="250000" currency_symbol="$" default_rate="5.5"]
```
